Orion Query Pack

How to test
  1. Open http://localhost:4181, choose Cases, then orion-lahore-reference-20261030, then the tab Ask this case.
  2. Copy a question with its button and paste it into the box. An answer takes 15 to 120 seconds.
  3. Read the first sentence, the table, the notes, then How was this answered. Compare with Expected, mark Pass or Fail, and write what you saw.
  4. Honesty checks matter as much as answers: a question the case cannot answer must be declined or answered "nothing found", never guessed.
  5. Connection questions expect the case's hub threshold of 10, which is set on this case; each such answer says "Hub threshold used: 10 subscribers (the setting of this case...)". To see the setting at work, put your own number in a question ("...leaving out numbers in contact with more than 5 subscribers") and the answer says "read from your question". Change the case's value with python -X utf8 tools/showcase/set_case_setting.py --case orion-lahore-reference-20261030 --hub-threshold 20 --apply (and set it back to 10).
