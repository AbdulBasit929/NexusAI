# Question catalogue: what the application answers, measured (2026-11-24)

Every question below comes from a bank that was put to the **live Ask engine** on the **Orion Lahore reference case** (`orion-lahore-reference-20261030`, synthetic records, a few real public recordings and five real video clips whose plates are masked). The expected answer of each question was computed from the stored rows by a query that does not go through the engine, and the engine's answer was scored against it. Nothing in this file was written by hand except the notes and the list of what cannot be answered yet. It is generated by `tools/showcase/build_question_catalogue.py`; the full list, one row per question, is `docs/qa/question-catalogue-20261124.csv` (920 rows).

**How to read the status.** *answered correctly* = the expected answer is in the engine's answer. *abstained* or *declined* = the engine said it could not show the answer; that is honest and is counted apart from a wrong answer. *answered wrongly* = a wrong answer (none in the main bank today). Readings made by models (plates, speech, text in pictures) are **candidates that a person must check**; none is an identification.

## 8. How to test it yourself

1. In the interface (`http://localhost:4182` for the new design, `:4181` for the old one) open the case **Orion Lahore Reference** and put any question of section 2 into Ask, word for word or in your own words. Compare with the expected answer in the CSV.
2. To re-run a bank against the live engine (one question at a time; the model is one process, so allow minutes, not seconds):

```powershell
python -X utf8 tools/showcase/ask_case.py docs/qa/verified-bank-20261124.json --collection orion-lahore-reference-20261030 --out C:/tmp/results.jsonl --per-type 2
python -X utf8 tools/showcase/judge_verified_bank.py docs/qa/verified-bank-20261124.json C:/tmp/results.jsonl --out C:/tmp/sheet
```

3. To re-ask the where-is-it-written banks: `python -X utf8 tools/showcase/ask_exhaustive_bank.py --out C:/tmp/bank.jsonl --bank bank-C`, then `ask_exhaustive_score.py C:/tmp/bank.jsonl --list`.
4. Questions that name a plate of the real video clips are typed from the private file (`C:/NexusAI-Showcase/orion/key/video-private-bank.json`, outside the repository); the sheets show `<PLATE>`.
5. A new bank must be written **after** the build it certifies and asked once; a bank whose misses were read is a diagnostic, not a gate.
