# U1 evidence

`metrics.json` is generated by
`apps/investigation-workspace/design/measure-foundations.mjs` against the local
`/design/foundations` route after a production build.

The run uses eight trusted Chromium clicks for each of three interactions. The
Event Timing values are local laboratory measurements, not field INP; the
double-`requestAnimationFrame` values are an additional interaction-to-next-paint
proxy. The bundle section reads the built files and records raw and gzip bytes.

Visual QA on 2026-10-28 covered Direction A light and dark, Direction B dark,
and the 390 px preview through the visible local browser. The narrow Case
Overview reflowed to one column with no page-level horizontal clipping. The
remaining combinations are generated from the same controls and are exercised
by `FoundationsPage.vitest.jsx`.

Reproduce from `apps/investigation-workspace` while the owner-provided server is
running on port 4182:

```text
npm run build
npm run measure:foundations
```
