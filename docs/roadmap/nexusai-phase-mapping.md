# NexusAI historical-to-active phase mapping

Status: governance correction adopted 2026-08-06  
Authority: `NEXUSAI_MASTER_DIRECTIVE.md`

## Namespace rule

The repository contains two valid but different phase namespaces:

- **Historical baseline phases** describe accepted or attempted work completed
  before the R-program was adopted. They remain evidence and must not be renamed.
- **Active transformation phases R0-R17** govern all work from this correction
  forward. Only an R-phase may be called the current program phase.

Historical Phase 7.3 is an accepted professional answer-presentation baseline.
It is not the current phase, does not complete R6, and does not authorize the
deferred Agent Chat lifecycle slice.

## Work-item correction

`R4-PRE-01 — Truthful Case Workspace initialization` is a pre-phase
source-accepted fix. It prevents a transient loading state from falsely reporting
zero evidence and records. It is runtime-pending and:

- does not complete R4;

- remains protected until a separately approved guarded deployment.

## Forward naming contract

Every new task, report, checkpoint entry, and next action must include an R-phase
identifier. Historical identifiers may appear only as preserved evidence,
capability provenance, or mapping context. Source, deployment, runtime, and data
acceptance must be reported independently.
