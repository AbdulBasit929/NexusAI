# WI-UI-3 visual-review evidence

This directory contains the fixture-driven review set generated by
`e2e/visual-review.spec.js`:

- answered, clarification with options, zero-result, and failed;
- light and dark themes;
- 390 px and 1440 px viewports;
- an additional light-theme RTL answer at both widths.

The screenshots use checked repository fixtures for answered, clarification,
and zero-result states. The failed state uses a deterministic HTTP 500 and the
client's stable error-reference presentation.
