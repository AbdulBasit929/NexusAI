# WI-UI-6 visual review

This directory contains 73 deterministic PNGs generated by Playwright:

- 56 LTR route/state screenshots across Daylight Ledger and Operations Slate
  at 390, 820, 1024, and 1440 px;
- 8 RTL answer screenshots across both themes and all four widths;
- 8 mixed-script type proofs across both themes and all four widths;
- 1 desktop aggregate-citation rail detail.

The type proof renders the four required corpus strings at caption, label,
body-sm, body, title-sm, title, and display. Browser assertions check the same
computed line height for all four strings at each step, LTR `bdi` isolation for
`03001234567` and `1035`, Noto family selection, baseline alignment, one H1,
LTR shell direction, and zero horizontal overflow.

See `contrast-report.md` for the measured adjacent-surface ratios.
